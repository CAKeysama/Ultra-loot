# Ultra Loot — Asset specification

Namespace: `ultraloot`. All textures are original pixel art (16x16 unless noted), generated by
`tools/generate_assets.py` (Python 3.11 + Pillow). Blockbench is not installed: models are hand-authored
JSON using Minecraft's `elements` format. Never copy textures/models from Mekanism or any other mod.

## Visual identity

- Body: dark graphite steel (`#2B2F36` → `#4A505A`) with bevelled edges and rivets.
- Accent per **family**: Loot Generator = treasure gold/amber (`#E8B23A`), Mob Loot Generator = soul teal (`#3FD0C9`).
- Accent per **tier** (trim stripe / corner plates): T1 iron `#C8C8C8`, T2 gold `#F2C94C`, T3 emerald `#3DDC84`, T4 nether-star violet `#C9A0FF` (with a brighter glow pixel).
- Front face: Loot Generator shows a vault/chest-lid motif with a glowing slot; Mob Loot Generator shows a caged soul core.
- `active=true` front texture lights the core (brighter accent + glow pixels).

## Blocks (8)

`loot_generator_t1..t4`, `mob_loot_generator_t1..t4`

Blockstate properties: `facing` (north/east/south/west), `active` (true/false). Rotate with `y`.
Models: one parent per family with elements (base slab, body, frame pillars, top cap) that is not a plain cube;
T4 adds an extra top element (antenna/crystal). Tier differences come from textures + T4 extra element.
Texture slots per model: `front`, `front_on`(via separate model), `side`, `top`, `bottom`, `particle`.
Item models: parent the block model (inactive).
